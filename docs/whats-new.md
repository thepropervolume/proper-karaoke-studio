# What’s New in Karaoke Studio

## 0.12.4

- Refine the Signature Band splash and its accessible open-source license explanation.

## 0.12.3

- Refresh the Studio splash with KaraStudio branding, the selected Signature Band design, and a licensing tooltip.

## 0.12.2

- Start Studio with a Day or Night splash that follows the app’s appearance and links to The Proper Volume.
- Show the Studio name and version separately in Windows Installed apps and preserve existing shortcuts when upgrading in place.

## 0.12.1

- Export CD+G with clearer, bolder lyrics, safer margins for wide lines, and a magenta highlight sweep that keeps the letters intact.
- Draw incoming rows more evenly while the current lyric is being highlighted.

## 0.12.0

- Shift word and line timings for one cue, a selection, or the whole song.
- Save lyric appearance and title screen defaults, and transfer named presets between computers.
- Add a logo, title screens, and opening or closing MP4 or WebM animations. Preview the full sequence before exporting.
- Save separated stems beside the project and keep working on lyrics while separation runs.
- Check the app version in **Help → About**.

## 0.11.8

- Qwen3 bounds timestamp predictions to the selected audio.
- WhisperX can sync lyrics when its optional sentence tokenizer is missing or blocked.
- AI Sync errors show the failure without model-loading progress.

## 0.11.7

- Help includes bundled documentation, keyboard shortcuts, and a manual update check.
- Studio announces available updates when it opens.
- Desktop packages carry additional app search terms.
